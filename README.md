# Առակի ձայնը

Հայերեն միջնադարյան ոճով զրույցային կայք՝ Մխիթար Գոշի, Վարդան Այգեկցու և Եզոպոսի առակների շուրջ։

## Արագ ցուցադրություն՝ առանց API-ի

Բացեք `index.html` ֆայլը Chrome-ում, Edge-ում կամ Firefox-ում։ Հարցերի համար կաշխատեն տեղային, պատրաստված պատասխանները։

## Միացնել Google AI Studio-ի Gemini API-ն

Պետք է տեղադրված լինի Node.js 18 կամ ավելի նոր տարբերակ։ API բանալին չի գրվում կայքի HTML/JavaScript-ում. այն մնում է տեղային սերվերի `.env` ֆայլում։

1. Google AI Studio-ում ստեղծեք API բանալի՝ [aistudio.google.com/apikey](https://aistudio.google.com/apikey)։
2. Այս թղթապանակում բացեք PowerShell-ը և պատճենեք կարգավորման ֆայլը.

   ```powershell
   Copy-Item .env.example .env
   ```
3. Բացեք `.env`-ը և `GEMINI_API_KEY=`-ից հետո տեղադրեք ձեր բանալին։ Մի ավելացրեք չակերտներ և մի կիսվեք `.env` ֆայլով։
4. Բացեք PowerShell-ը այս թղթապանակում և աշխատեցրեք.

   ```powershell
   node server.mjs
   ```

5. Բրաուզերում այցելեք [http://127.0.0.1:4173](http://127.0.0.1:4173)։ Երբ սերվերն աշխատում է, զրույցը պատասխանում է Gemini-ով։ API բանալու բացակայության կամ ժամանակավոր սխալի դեպքում էջը վերադառնում է պատրաստի ցուցադրական պատասխաններին։

Սերվերը լսում է միայն ձեր համակարգչի տեղային հասցեն։ Բանալին պահվում է սերվերի միջավայրում և ուղարկվում է Google-ի պաշտոնական `generateContent` API-ին սերվերից։ Լռելյայն օգտագործվում է `gemini-3.5-flash-lite` մոդելը, որի տեքստային մուտքն ու ելքը Google-ի ընթացիկ գնացուցակում նշված են անվճար շերտում։ Անվճար քվոտան, հասանելիությունը և սահմանաչափերը կարող են փոխվել։[¹](https://ai.google.dev/gemini-api/docs/pricing)

## Առակագիրների ԱԲ կերպարները

Սերվերում յուրաքանչյուր կերպարի համար գրված է իր առանձին հայերեն համակարգային հրահանգը։ Գոշի կերպարը կենտրոնանում է արդարության ու խղճի վրա, Այգեկցունը՝ կենդանիների այլաբանության ու մեղմ երգիծանքի, իսկ Եզոպոսինը՝ կարճ պատմության և հստակ բարոյական մտքի վրա։ «Ո՞վ ես դու» հարցին կերպարները պատասխանում են առաջին դեմքով՝ իրենց անունով, իսկ ԱԲ լինելը բացահայտում են, երբ այդ մասին ուղղակի հարցնում են։ Կայքի զրույցի վերնամասում միևնույն է նշված է, որ կերպարները ԱԲ մեկնաբանություններ են։

## Ֆայլեր

- `index.html` — կայքի էջը
- `styles.css` — միջնադարյան տեսքն ու հարմարեցումը հեռախոսներին
- `app.js` — զրույցի ինտերֆեյսը և ցուցադրական պահուստային պատասխանները
- `server.mjs` — տեղային վեբ սերվերը և Google Gemini-ի անվտանգ սերվերային կապը
- `.env.example` — API բանալու կարգավորման օրինակ
